One-time setup

This runs entirely on your machine, so it needs your own Spotify app credentials. Nothing is sent anywhere except to Spotify.

  1. Open the Spotify Developer Dashboard and click Create app.
  2. Give it any name. Under APIs used, tick Web API and Web Playback SDK.
  3. Set the Redirect URI to exactly this, then click Add:
  4. Save, then copy the app's Client ID and paste it here.

Spotify Premium is required — the Web Playback SDK will not play audio on a free account. Apps start in development mode, so anyone else who wants to play must be added under Settings › User Management in your dashboard (25 max).

Connect Spotify

You'll be sent to Spotify to authorise, then straight back here.

Pick a playlist

Spotify's own editorial and algorithmic playlists (Discover Weekly, Today's Top Hits…) are blocked by the API for new apps. Use a playlist made by a person.
